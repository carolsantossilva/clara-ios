# Patterns that turn a check off. Adding any of them in a PR requires the
# "guardrail-exception" label (a human decision, justified in the PR).
# Format: <Python regex>\t<explanation>
swiftlint:disable	turns off a SwiftLint rule
swiftformat:disable	turns off SwiftFormat
@(Test|Suite)\b.*\.disabled\(	disables a Swift Testing test
XCTSkip	skips an XCTest test
withKnownIssue	marks a test failure as expected
@unchecked\s+Sendable	turns off the compiler's concurrency checking
nonisolated\(unsafe\)	turns off isolation checking
@preconcurrency	suppresses concurrency warnings from an import
\bisRecording\s*=\s*true	re-records snapshot references
record:\s*\.(all|missing|failed)	re-records snapshot references
\btry!	can crash the app at runtime
